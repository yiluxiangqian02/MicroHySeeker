# AutoHySeeker Web UI 规划 V2.0

> **核心定位**：AutoHySeeker 是控制 MicroHySeeker 电化学工作站的智能决策中心  
> **最后更新**：2026-03-09  
> **架构**：AutoHySeeker（5个AI Agent）→ MicroHySeeker（PySide6 GUI）→ 硬件设备

---

## 🎯 核心理念

**AutoHySeeker 不是 API 监控工具，而是实验自动化的大脑**

- **MicroHySeeker**：手动操作界面，人工设计实验、点击运行、查看数据
- **AutoHySeeker**：AI 驱动的实验控制中心，自动设计→执行→分析→优化的闭环

---

## 📐 系统架构理解

### 三层架构

```
┌─────────────────────────────────────────────────────────┐
│  AutoHySeeker Web UI (React)                            │
│  - 实验设计与审批                                        │
│  - 实时监控与干预                                        │
│  - 数据分析与决策                                        │
│  - Agent 配置与管理                                      │
└────────────────┬────────────────────────────────────────┘
                 │ HTTP API
┌────────────────▼────────────────────────────────────────┐
│  AutoHySeeker Backend (FastAPI + LangGraph)             │
│  - 5 个 AI Agent（数据分析/故障诊断/实验设计/监控/知识）│
│  - LangGraph 工作流编排                                  │
│  - OpenViking 知识库                                     │
└────────────────┬────────────────────────────────────────┘
                 │ HTTP/WebSocket
┌────────────────▼────────────────────────────────────────┐
│  MicroHySeeker (PySide6 GUI)                            │
│  - 程序编辑器（配液/电化学/冲洗/移液）                   │
│  - 硬件控制（RS485 泵、CHI 电化学工作站）                │
│  - 实时数据采集                                          │
└────────────────┬────────────────────────────────────────┘
                 │ RS485 / USB
┌────────────────▼────────────────────────────────────────┐
│  硬件设备                                                │
│  - 蠕动泵（1-12 台）                                     │
│  - CHI 电化学工作站                                      │
│  - 微流控芯片                                            │
└─────────────────────────────────────────────────────────┘
```

### MicroHySeeker 核心功能

**实验步骤类型：**
1. **配液 (prep_sol)** - 多溶液混合配制目标浓度
2. **电化学 (echem)** - CV/LSV/EIS/ADT 测试
3. **冲洗 (flush)** - 清洗管路和芯片
4. **移液 (transfer)** - 溶液转移
5. **空白 (blank)** - 延时等待
6. **排空 (evacuate)** - 排空管路

**硬件控制：**
- 12 台 RS485 蠕动泵（独立地址、转速、方向）
- CHI 电化学工作站（CV/LSV/EIS/ADT）
- 配液通道（溶液名称、浓度、泵地址）
- 冲洗通道（Inlet/Transfer/Outlet）

**数据输出：**
- 实验日志（run_log.log）
- 电化学数据（CSV 文件）
- 实验摘要（run_summary.json）

### 4. Analysis（数据分析）

**目标**：深度分析实验数据，提取知识

**四个子页面：**

#### 4.1 单实验分析
- 上传/选择实验数据
- 自动识别技术类型（CV/LSV/EIS）
- 调用数据分析 Agent
- 显示分析结果：
  - CV：峰电位、峰电流、Tafel 斜率
  - LSV：起始电位、电流密度
  - EIS：阻抗谱拟合、等效电路

#### 4.2 趋势对比
- 选择多个实验（时间序列）
- 对比关键指标：
  - 峰电流趋势图
  - Tafel 斜率变化
  - 起始电位漂移
- AI 解读趋势（知识管理 Agent）

#### 4.3 参数优化
- 选择优化目标（如最大化电流密度）
- 选择优化参数（扫速、浓度、pH）
- 调用贝叶斯优化
- 可视化参数空间

#### 4.4 知识提取
- 从实验中提取可复用知识
- 保存到 OpenViking 知识库
- 标注和组织文献
