## Agent 分工规则

### Copilot（GitHub Copilot / Claude 系列）
- **擅长**：复杂算法、大重构、跨文件分析、消耗 token 多的任务
- **计费**：按次数，所以每次任务要尽量多做
- **常用模型**：claude-sonnet-4.6（日常）/ claude-opus-4.6（难题）
- **升级规则**：同一问题 sonnet 连续 2 次失败 → 自动切 opus
- **典型任务**：贝叶斯优化实现、LangGraph 节点、数据分析算法

### Codex（OpenAI Codex CLI）
- **擅长**：小型修复、局部调试、单文件改动、token 消耗短的任务
- **计费**：按 token，保持 prompt 简洁
- **典型任务**：bug fix、小功能、配置文件修改、格式化

### Claude Code（Anthropic Claude Code CLI）
- **擅长**：后端逻辑、硬件驱动代码、多文件理解
- **计费**：按 token
- **典型任务**：硬件适配层、API 接口、测试编写

## 文件安全规则（兜底保护）

以下文件/目录 **禁止删除或覆盖**，任何 Agent 操作前必须确认：

```
MicroHySeeker/src/                  # 核心源码
MicroHySeeker/config/system.json    # 系统配置
data/                               # 实验数据（只读）
logs/                               # 日志（只读）
AutoHySeeker/OpenViking/            # 知识库
.git/                               # git 历史
```

**Agent 操作原则**：
- 优先在自己的 worktree 分支上操作，不直接改 main/autohyseeker
- 删除前必须先 `git add + commit`，确保可回滚
- 不对 `data/` 和 `logs/` 做任何写操作
